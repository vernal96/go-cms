# Core: типы полей

Каталог `core.field` предоставляет стандартные типы для полей шаблонов, ресурсов и других модулей. Определение поля задаёт код, тип, подпись, обязательность, правила и метаданные редактора.

| Код | Применение |
| --- | --- |
| `string`, `textarea`, `email`, `phone` | Текстовые значения; email проверяется как адрес, для телефона можно задать pattern |
| `int`, `float`, `checkbox` | Числа и логическое значение |
| `radio`, `select` | Выбор значения из `choices` |
| `file`, `media` | Ссылка на файл из разрешённых дисков или на media |
| `json` | Структурированные JSON-значения |
| `repeater` | Повторяемые вложенные значения с дочерними определениями |

Пример поля, объявляемого в шаблоне:

```go
field.Definition{
    Key:   "summary",
    Type:  field.TypeTextarea,
    Label: "Краткое описание",
}
```

Для `radio` и `select` в `Options` передаётся список choices; для `file` можно ограничить диски и MIME-типы. Тип значения отвечает за нормализацию/валидацию, а `Editor`/metadata описывают его административное представление. Поля настроек сайта `Profile.Params` — отдельный контракт, описанный в [профилях](../../profiles.md).
