# Mail

`mail` предоставляет шаблоны, постановку писем в очередь и историю попыток доставки. Зависит от `core`; в Starter не включён.

См. [сущности](entities.md), [API](api.md), [виджеты](widgets.md) и [фоновые задачи](background.md). Для доставки приложение подключает transport; для SMTP доступны настройки соответствующего транспорта. Параметры `mail.Config` управляют лимитами, повторами, retention и attachment storage.
